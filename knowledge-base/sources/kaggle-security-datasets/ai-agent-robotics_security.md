- attack_id: ROB-001 | attack_name: ROS Topic Injection | attack_type: Communication Injection | target_system: ROS 1 (Robot Operating System) | target_component: ROS Topic / Message Bus | attack_method: Attacker on the same network publishes malicious ROS messages to robot control topics, overriding legitimate commands | impact: Robot arm movement to dangerous positions, collision, injury | severity_score: 9.8 | risk_level: Critical | real_world_ref: Vulnerabilities in ROS 1 (Alias Robotics Security Research 2020) | year: 2020 | mitigation: Migrate to ROS 2 with DDS security, network segmentation, topic authentication | source: Alias Robotics CVE Database 2020
- attack_id: ROB-002 | attack_name: Industrial Robot Arm Hijacking | attack_type: Control System Attack | target_system: ABB, FANUC, KUKA Robot Arms | target_component: Robot Controller (IRC5/R-30iB) | attack_method: Exploitation of unpatched vulnerabilities in industrial robot controller web interface, modifying motion programs remotely | impact: Product sabotage, physical injury to workers, manufacturing defects | severity_score: 10.0 | risk_level: Critical | real_world_ref: Rogue Robots: ABB/FANUC controller vulnerabilities (Trend Micro 2017) | year: 2017 | mitigation: Network isolation, controller firmware patching, integrity monitoring of motion programs | source: Trend Micro / Politecnico di Milano 2017
- attack_id: ROB-003 | attack_name: Drone GPS Spoofing Takeover | attack_type: Sensor Spoofing | target_system: DJI Phantom, commercial drones | target_component: GPS Navigation System | attack_method: SDR-based GPS spoofing causes drone to navigate to attacker-controlled location or trigger emergency landing | impact: Drone hijacking, cargo theft, physical danger | severity_score: 9.5 | risk_level: Critical | real_world_ref: Drone GPS Spoofing (University of Texas 2012, repeated 2019) | year: 2019 | mitigation: GPS signal authentication, inertial navigation backup, geofencing enforcement | source: University of Texas Radionavigation Lab 2019
- attack_id: ROB-004 | attack_name: ROS 2 DDS Discovery Attack | attack_type: Network Discovery Exploitation | target_system: ROS 2 / DDS-based robots | target_component: DDS Discovery Protocol | attack_method: Attacker joins ROS 2 DDS domain and discovers all robot topics, then publishes to sensitive control topics | impact: Unauthorized robot control, DoS | severity_score: 8.7 | risk_level: High | real_world_ref: Security Analysis of ROS 2 (White Paper, SROS2 2021) | year: 2021 | mitigation: Enable SROS2 security plugins, restrict DDS domain access, use DDS-Security 1.1 | source: SROS2 Security Working Group 2021
- attack_id: ROB-005 | attack_name: LLM-Robot Prompt Injection | attack_type: Prompt Injection | target_system: LLM-controlled robots (Figure 01, Boston Dynamics) | target_component: LLM Natural Language Interface | attack_method: Malicious voice command or text input causes LLM-controlled robot to perform dangerous physical actions | impact: Physical harm, property damage, unsafe robot behavior | severity_score: 9.9 | risk_level: Critical | real_world_ref: LLM Robot Safety Failures (Carnegie Mellon / Brown University 2024, arXiv:2402.11208) | year: 2024 | mitigation: LLM output safety classifier, physical action confirmation step, emergency stop trigger | source: arXiv:2402.11208 (2024)
