# AI Agent Cybersecurity - agent_attack_taxonomy

- attack_type: Prompt Injection | category: Input Manipulation | subcategory: Direct Injection | description: Attacker embeds malicious instructions in user input that override the agent's system prompt or intended behavior. | target_component: LLM System Prompt | impact: Unauthorized actions, data leakage, safety bypass | owasp_ref: LLM01:2025 | mitre_atlas_ref: AML.T0051 | severity_range: High to Critical | example_frameworks: LangChain, OpenAI Agents SDK, AutoGPT | real_world_incidents: Bing Chat DAN jailbreak 2023; ChatGPT markdown injection
- attack_type: Indirect Prompt Injection | category: Input Manipulation | subcategory: Environment-Mediated Injection | description: Hidden malicious instructions in external content (websites, emails, documents) that an agent reads, hijacking its subsequent actions. | target_component: Agent Tool Outputs (Web, Email, Files) | impact: Agent hijacking, data exfiltration, unauthorized actions | owasp_ref: LLM01:2025 | mitre_atlas_ref: AML.T0051.001 | severity_range: Critical | example_frameworks: AutoGPT, OpenAI Agents SDK, LangChain | real_world_incidents: Greshake et al. arXiv:2302.12173; Microsoft Copilot email injection PoC
- attack_type: Tool Poisoning | category: Supply Chain Attack | subcategory: Malicious Tool Registration | description: Attacker registers or modifies an agent's available tools to perform malicious actions while appearing legitimate. | target_component: Agent Tool Registry / MCP Server | impact: Data exfiltration, arbitrary code execution, lateral movement | owasp_ref: LLM06:2025 | mitre_atlas_ref: AML.T0054 | severity_range: Critical | example_frameworks: LangChain, CrewAI, OpenAI Agents SDK | real_world_incidents: Invariant Labs MCP Tool Poisoning PoC 2025
- attack_type: Memory Poisoning | category: Persistence | subcategory: Long-Term Memory Corruption | description: Injection of malicious 'memories' into the agent's persistent memory store (vector DB) that surface in future sessions to influence decisions. | target_component: Agent Memory: Vector Database (ChromaDB, Pinecone) | impact: Persistent agent compromise, biased future decisions, backdoor implantation | owasp_ref: LLM03:2025 | mitre_atlas_ref: AML.T0053 | severity_range: High to Critical | example_frameworks: AutoGPT, LangChain, MemGPT | real_world_incidents: AutoGPT persistent memory injection PoC (GitHub, 2023)
- attack_type: RAG Poisoning | category: Data Poisoning | subcategory: Knowledge Base Contamination | description: Attacker uploads or injects malicious documents into the agent's Retrieval-Augmented Generation knowledge base to manipulate its responses. | target_component: RAG Vector Store / Document Index | impact: Misinformation, agent hijacking, confidentiality breach | owasp_ref: LLM03:2025 | mitre_atlas_ref: AML.T0053.001 | severity_range: High to Critical | example_frameworks: LangChain, LlamaIndex, CrewAI | real_world_incidents: NVIDIA AI Red Team Phantom Documents attack 2024
- attack_type: Agent Hijacking | category: Control Takeover | subcategory: Goal Redirection | description: Attacker takes full control of an autonomous agent's goal or action pipeline, redirecting it to perform attacker-defined tasks. | target_component: Agent Orchestrator / Goal System | impact: Complete agent compromise, unauthorized actions at scale | owasp_ref: LLM08:2025 | mitre_atlas_ref: AML.T0048 | severity_range: Critical | example_frameworks: AutoGPT, CrewAI, OpenAI Agents SDK | real_world_incidents: ComPromptMized GenAI Worm arXiv:2403.02817 (2024)
- attack_type: Jailbreak | category: Guardrail Bypass | subcategory: Persona Injection | description: Attacker bypasses model safety guardrails through role-play, persona-switching, or encoding tricks to elicit harmful outputs. | target_component: LLM Safety Guardrails / RLHF Fine-tuning | impact: Harmful content generation, safety bypass, policy violation | owasp_ref: LLM01:2025 | mitre_atlas_ref: AML.T0051 | severity_range: Medium to High | example_frameworks: OpenAI Agents SDK, LangChain, AutoGPT | real_world_incidents: DAN jailbreak (2023); Many-shot jailbreaking (Anthropic 2024)
- attack_type: Model Supply Chain Attack | category: Supply Chain Attack | subcategory: Backdoored Weights | description: Malicious model weights with embedded backdoors uploaded to public model repositories (e.g., Hugging Face) and used in agent pipelines. | target_component: LLM Model Weights | impact: Persistent backdoor, triggered malicious behavior, data exfiltration | owasp_ref: LLM05:2025 | mitre_atlas_ref: AML.T0018 | severity_range: Critical | example_frameworks: LangChain, LlamaIndex, Hugging Face Transformers | real_world_incidents: Hugging Face malicious model uploads 2024; PyTorch torchvision supply chain 2022
- attack_type: Excessive Agency Exploitation | category: Privilege Escalation | subcategory: Overpermissioned Agent | description: Agent given excessive permissions (file system, email, database) is exploited via prompt injection to perform destructive or unauthorized operations. | target_component: Agent Permission Model / Tool Scope | impact: Data deletion, exfiltration, unauthorized system changes | owasp_ref: LLM08:2025 | mitre_atlas_ref: AML.T0054 | severity_range: High to Critical | example_frameworks: LangChain, AutoGPT, OpenAI Agents SDK | real_world_incidents: LangChain Agent with shell tool privilege escalation PoC (2024)
- attack_type: Denial of Service (Prompt Bomb) | category: Availability Attack | subcategory: Compute Resource Exhaustion | description: Specially crafted complex or recursive prompts that force maximum token generation and compute usage, causing API timeouts or financial damage. | target_component: LLM API Compute / Token Budget | impact: Service unavailability, financial cost amplification | owasp_ref: LLM04:2025 | mitre_atlas_ref: AML.T0040 | severity_range: Medium to High | example_frameworks: All LLM-based agent frameworks | real_world_incidents: Sponge Examples attack (Shumailov et al. 2021); Token DoS on public endpoints
- attack_type: Training Data Extraction | category: Data Exfiltration | subcategory: Memorization Exploitation | description: Attacker crafts prompts that cause the LLM to regurgitate memorized training data including PII, proprietary code, or sensitive information. | target_component: LLM Training Data | impact: PII leakage, IP theft, compliance violations (GDPR, HIPAA) | owasp_ref: LLM02:2025 | mitre_atlas_ref: AML.T0024 | severity_range: Medium to High | example_frameworks: OpenAI Agents SDK, General LLM APIs | real_world_incidents: Carlini et al. GPT-2 data extraction; Samsung code leak via ChatGPT 2023
- attack_type: Multi-Agent Orchestrator Compromise | category: Control Takeover | subcategory: Pipeline Hijacking | description: In multi-agent systems, a compromised sub-agent sends malicious instructions upward to the orchestrator, taking over the entire agent pipeline. | target_component: Multi-Agent Orchestrator | impact: Full pipeline compromise, cascading unauthorized actions | owasp_ref: LLM08:2025 | mitre_atlas_ref: AML.T0048 | severity_range: Critical | example_frameworks: CrewAI, AutoGen, LangChain | real_world_incidents: CrewAI orchestrator injection PoC (Marcus Hallberg, 2025)
